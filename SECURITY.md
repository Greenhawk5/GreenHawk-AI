---

# Reporting a Vulnerability

If you discover a security issue, please do not publicly disclose it.

Instead, report it privately through:

GitHub Security Advisories:

https://github.com/Greenhawk5/GreenHawk-AI/security

---

# Examples of Security Issues

Please report issues related to:

- API vulnerabilities
- Unauthorized access
- File upload vulnerabilities
- Exposure of sensitive information
- Dependency vulnerabilities

---

# Response Process

After receiving a report:

1. The issue will be reviewed.
2. The vulnerability will be investigated.
3. A fix will be prepared if necessary.
4. A security update may be released.

---

# Responsible Disclosure

Please allow reasonable time for fixing security problems before public disclosure.

Thank you for helping keep GreenHawk AI secure.
